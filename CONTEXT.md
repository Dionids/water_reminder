# Дипломный проект — Water Reminder

## Описание
Мобильное приложение-напоминалка для питья воды с уведомлениями
на смарт-часах. Норма воды рассчитывается динамически на основе
физической активности пользователя.

## Стек технологий
- Flutter (Dart) — кроссплатформенный фронтенд
- Android Studio — IDE
- FastAPI (Python) — бэкенд, расчёт нормы воды + ИИ аналитика
- PostgreSQL — основная база данных
- Isar (NoSQL) — локальная БД на телефоне (оффлайн-режим)
- Пакет `health` — чтение данных с часов

## Целевые платформы
- Android + Samsung Galaxy Watch (Health Connect API)
- Android + Huawei Watch (HMS Health Kit)
- iOS + Apple Watch (HealthKit)

## Данные с часов
Читаем только два типа данных:
- Шаги (StepsRecord / HKQuantityType.stepCount)
- Тренировки (ExerciseSessionRecord / HKWorkoutType)

## Формула расчёта нормы воды
base_ml     = weight_kg × 30          // базовая норма ВОЗ
workout_bonus = (workout_min / 30) × 500  // +500 мл за каждые 30 мин
steps_bonus   = max(0, (steps - 5000) / 5000) × 200  // +200 мл за 5k шагов
total = base_ml + workout_bonus + steps_bonus

## Архитектура (Offline-first)
Часы → синхронизируют данные в системное хранилище телефона
Телефон (Flutter) → читает данные через health пакет → **сохраняет в Isar (локально)**
Телефон → Синхронизация с бэкендом (POST /activity) при наличии сети
Бэкенд → считает норму, возвращает water_goal_ml
Телефон → показывает норму, отправляет уведомления на часы

## Ключевые экраны (запланированы)
1. HomeScreen — прогресс воды за день, кнопки +150/250/500 мл
2. ProfileScreen — вес, рост, возраст пользователя
3. HistoryScreen — график потребления за неделю (данные из локальной БД)
4. SettingsScreen — интервал уведомлений, цель

## Уведомления
- Отправляются на часы через flutter_local_notifications
- **Оптимизация**: проверка ЧСС/активности не чаще раза в 30-60 мин для экономии заряда.
- Умный контекст: не тревожить во время сна (на основе данных о сне или ЧСС < 60).
- Адаптивный интервал: если пользователь пьёт регулярно — реже.

## Виджет на циферблате (планируется)
- Apple Watch: Complication через WidgetKit
- Samsung/Wear OS: Tile через Jetpack Compose
- Huawei: Watchface extension (HarmonyOS FA card)

## Бэкенд эндпоинты
POST /activity    — принимает шаги + тренировки, возвращает норму
POST /water-log   — записывает факт выпитой воды
GET  /stats       — статистика за период
GET  /get-advice  — персонализированный совет (на основе погоды и активности)

## Безопасность и конфиденциальность
- Минимизация данных: храним только необходимые метрики активности.
- Обезличивание: данные о здоровье в БД бэкенда не содержат ФИО пользователя.
- Локальное шифрование: использование защищенного хранилища для токенов доступа.
