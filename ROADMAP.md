# План реализации (Roadmap) — Water Reminder

## Спринт 1: База данных и Локальная логика (1-2 недели)
- [ ] Инициализация Isar БД в проекте.
- [ ] Создание моделей данных:
    - `WaterLog` (количество, время, тип напитка).
    - `UserProfile` (вес, возраст, базовая норма).
    - `ActivityCache` (шаги, тренировки, фазы сна).
- [ ] Разработка `DataRepository` для CRUD операций.
- [ ] Реализация простого UI для проверки сохранения данных.

## Спринт 2: Health Integration (2 недели)
- [ ] Настройка манифестов разрешений (Health Connect для Android, Info.plist для iOS).
- [ ] Создание `HealthService` для чтения данных за день.
- [ ] **Data Sync**: Автоматическое сохранение данных из Health в локальный Isar при запуске.
- [ ] Обработка статуса сна (`SLEEP_ASLEEP`) для блокировки уведомлений.

## Спринт 3: Backend & Sync (2 недели)
- [ ] FastAPI: Создание моделей PostgreSQL (SQLAlchemy/SQLModel).
- [ ] Реализация формулы динамического расчёта на сервере.
- [ ] Эндпоинты:
    - `POST /sync-activity`: Приём данных о шагах/тренировках -> Возврат `daily_goal`.
    - `POST /log-water`: Синхронизация выпитой воды.
- [ ] Интеграция `http` пакета во Flutter для связи с сервером.

## Спринт 4: Умные уведомления (1 неделя)
- [ ] Интеграция `flutter_local_notifications`.
- [ ] Реализация алгоритма проверки:
    - Интервал (например, каждые 2 часа).
    - Проверка на «сон»: если датчик показывает сон, пуш отменяется.
    - Проверка прогресса: если цель достигнута, пуши прекращаются.

## Спринт 5: UI/UX и Аналитика (1 неделя)
- [ ] **Onboarding Screen**: Обязательный ввод веса и возраста при первом запуске.
- [ ] Дизайн главного экрана: анимированный индикатор уровня воды.
- [ ] Экран истории: графики за неделю (пакет `fl_chart`).
- [ ] Экран настроек: управление интервалами уведомлений.

## Спринт 6: Часы и Полировка (1-2 недели)
- [ ] Настройка синхронизации уведомлений с Wear OS / Apple Watch.
- [ ] (Advanced) Реализация Tile (плитки) для Wear OS через нативный код (Jetpack Compose).
- [ ] Тестирование на реальных устройствах.
- [ ] Подготовка документации для диплома.

---
**Итого ориентировочно:** 8–10 недель до финальной версии.
