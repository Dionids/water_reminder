# Техническая документация проекта: Water Reminder AI

## 1. Описание проекта
**Water Reminder AI** — это инновационное мобильное приложение для контроля водного баланса, которое динамически рассчитывает норму воды на основе физической активности пользователя, получаемой со смарт-часов и датчиков телефона.

### Ключевые особенности:
- **Динамическая цель**: Норма воды пересчитывается в реальном времени при изменении количества шагов или появлении тренировок.
- **Умные советы**: Бэкенд на базе Python анализирует активность и выдает персональные рекомендации.
- **Offline-first**: Приложение сохраняет все данные локально и синхронизирует их с сервером при наличии сети.
- **Интеграция с Health-системами**: Поддержка Apple HealthKit (iOS) и Google Health Connect (Android).

---

## 2. Архитектура системы
Проект реализован на базе клиент-серверной архитектуры:

### Фронтенд (Mobile App):
- **Framework**: Flutter (Dart).
- **База данных**: Isar (NoSQL) — используется для мгновенного доступа к данным и оффлайн-режима.
- **Датчики**: Пакет `health` для агрегации данных из системных хранилищ ОС.
- **State Management**: StatefulWidget + Services (Service-Oriented Architecture).

### Бэкенд (Server):
- **Framework**: FastAPI (Python).
- **Логика**: Расчет формулы нормы воды и генерация текстовых советов.
- **API**: RESTful API (JSON).

---

## 3. Реализация ключевых модулей

### Локальное хранение (`lib/services/isar_service.dart`)
Реализовано через Isar. Основные сущности:
- `WaterLog`: Хранит записи о выпитой воде.
- `ActivityCache`: Кэширует данные с датчиков (шаги, сон), чтобы приложение могло работать без постоянного опроса системы.

### Работа с датчиками (`lib/services/health_service.dart`)
Использует системные API:
- **Android**: Health Connect. Требует разрешений `READ_STEPS` и `READ_SLEEP`.
- **iOS**: HealthKit. Требует ключей `NSHealthShareUsageDescription` в Info.plist.

### Синхронизация (`lib/services/api_service.dart`)
Отправляет накопленные данные об активности на сервер по адресу `http://<server_ip>:8000/sync-activity`.

## 4. Инструкция по запуску

### Запуск Бэкенда:
1. Перейдите в папку `backend/`.
2. Установите зависимости: `pip install -r requirements.txt`.
3. Запустите сервер: `python main.py`.
   - *Сервер будет доступен по адресу http://0.0.0.0:8000*.

### Запуск Мобильного приложения:
1. Убедитесь, что Flutter установлен.
2. Выполните `flutter pub get`.
3. Сгенерируйте модели БД: `dart run build_runner build`.
4. Запустите на эмуляторе или устройстве: `flutter run`.
   - *Для Android-эмулятора используется IP 10.0.2.2 для связи с локальным сервером.*

---

## 5. Особенности реализации для диплома
1. **Безопасность**: Приложение использует анонимный `user_id` для синхронизации, не передавая персональные данные.
2. **Оптимизация**: Использование кэширования (`ActivityCache`) снижает нагрузку на батарею устройства, так как опрос системных датчиков происходит только при необходимости.
3. **Масштабируемость**: Архитектура позволяет легко заменить текущие советы на ответы от реальной LLM (например, OpenAI API) в `backend/main.py`.
